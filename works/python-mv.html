Python-MV

Python-MV
Applications
CategoryApplications
TagsPython, Contributor, Tool
SourceGitHub ↗

An audio visualizer and music video renderer built in Python with a PySide6 interface. It decodes your audio with ffmpeg, analyzes it with numpy FFTs, draws every frame with Pillow, then pipes it all into ffmpeg to encode. Outputs MP4, WebM, GIF or a PNG sequence, and render setups can be saved as JSON presets.

My contributions

Everything from 0.5/1.0 is fully by me (idk what the owner is gonna do for the version.)

Features

  • FFT audio analysis with configurable size, overlap, window, frequency scale and band measure
  • Horizontal, Vertical and Radial bar layouts with gradients, glow and trails
  • Background image or video with darken, blur, zoom, pan and a bass-driven blur pulse
  • Overlays and post effects like Vignette, Scanlines, Grain, Chromatic, Bloom, Glitch and more
  • Batch rendering, JSON presets and a headless CLI
