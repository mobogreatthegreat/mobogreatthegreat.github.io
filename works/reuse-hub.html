A portable single-exe launcher for links, executables, and console commands, organized by colored categories.

What it is

It's two things taped together: a Python backend (FastAPI plus SQLite) that stores your items, and an Electron app that wraps it in a dark frosted-glass window. Both get bundled into one portable exe, so there's nothing to install.

Features

  • Launch websites, desktop apps and console commands from one place
  • Colored categories with a dedicated management modal
  • Grid and list views, with drag-and-drop reordering
  • Automatic icon extraction from executables, plus custom image icons
  • Console commands that can run in a visible terminal or silently in the background
  • Real-time search across names, paths and categories
  • Auto-update from GitHub releases

My contributions

I wrote the whole thing. The backend, the database, the launch logic, the Electron app, the build script. Some parts of the code and docs had AI help, but the core logic and backend are mine.
