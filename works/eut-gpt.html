A desktop interface and CLI for AI conversations powered by OpenCode, themed around the Everything Upgrade Tree wiki (and soon others..)

What it is

It's a Python CLI and an Electron app that both talk to an OpenCode server. The launcher installs and manages OpenCode by itself on first launch, and it doesn't run any AI models of its own. OpenCode does the model stuff, EUT-GPT is just the chat interface on top.

Features

  • Streaming responses with a typing indicator
  • Model switching, plus a thinking level from none up to max
  • Session management: rename by double-clicking, search, auto-naming
  • Temp chats that delete themselves when you switch away
  • Collapsible reasoning blocks
  • A CLI with a full command set, like /rename, /export and /history
  • Portable builds for Windows and Linux

Themes

12 color schemes, each named after a baseplate from the EUT wiki. There's astronomy, hardcore, prestige and qubits, to name a few.

My contributions

Core logic, the CLI and the build system are by me. Parts of the code and docs had AI help.
